# Мёртвая зона

Минималистичный top-down survival-прототип без сторонних зависимостей. Работает в современном мобильном или десктопном браузере.

## Запуск

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080`. На компьютере: WASD/стрелки, мышь и ЛКМ, клавиши 1–4, G — выбросить предмет из рук. На сенсорном экране используются два виртуальных стика и кнопки HUD, включая отдельную кнопку выброса.

## Одиночная игра и PvP по локальной сети

Установите зависимости и запустите авторитетный Node.js-сервер:

```bash
npm install
npm start
```

На компьютере сервера откройте `http://localhost:8080`. На втором устройстве в той же сети откройте LAN-адрес, напечатанный сервером, например `http://192.168.1.50:8080`. На стартовом экране выберите «PvP — подключиться». Оба устройства подключаются к одной общей эфемерной комнате; при перезапуске сервера мир создаётся заново.

Если второе устройство не подключается, проверьте локальный firewall и отсутствие AP/client isolation на Wi-Fi роутере. Для другого порта используйте `PORT=8090 npm start`.

Весь баланс находится в `config.js`. Игра не создаёт зомби на всей карте: поддерживается только ограниченный пул вокруг игрока, а далёкие сущности удаляются.
