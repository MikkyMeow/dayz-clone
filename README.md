# Мёртвая зона

Минималистичный top-down survival-прототип без сторонних зависимостей. Работает в современном мобильном или десктопном браузере.

## Запуск

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080`. На компьютере: WASD/стрелки, мышь и ЛКМ, клавиши 1–4, G — выбросить предмет из рук. На сенсорном экране используются два виртуальных стика и кнопки HUD, включая отдельную кнопку выброса.

Весь баланс находится в `config.js`. Игра не создаёт зомби на всей карте: поддерживается только ограниченный пул вокруг игрока, а далёкие сущности удаляются.
