## Коротко о проекте

DeadZone — top-down survival-игра на Canvas 2D, работающая в современном браузере. Есть два режима:

1. Одиночный: вся симуляция выполняется в браузере фиксированным шагом 60 Гц.
2. PvP: Node.js/WebSocket-сервер выполняет авторитетную симуляцию с частотой 30 Гц, а клиент отправляет ввод и интерполирует снимки, получаемые с частотой 15 Гц.

Сборщик отсутствует. Клиент использует нативные ES-модули, сервер — Node.js ESM. Единственная runtime-зависимость — `ws`.

## Главное правило согласованности

Изменение механики почти всегда нужно проверить в двух реализациях:

| Область | Одиночный режим | PvP |
|---|---|---|
| Основная симуляция | `js/gameplay.js`, `js/combat.js`, `js/zombies.js` | `server/game-session.js` |
| Ввод и действия | `js/input.js`, маршрутизация в `js/main.js` | `js/multiplayer-client.js`, `server/protocol.js` |
| Состояние | `js/state.js` | `GameSession`, затем snapshot в клиентский `state` |
| UI/отрисовка | общие `js/ui.js`, `js/renderer.js` | те же модули по серверным снимкам |

Если функция должна вести себя одинаково в обоих режимах, изменение только одной колонки считается незавершённым.

## Команды

```bash
npm install
npm test
npm start
```

`npm start` поднимает HTTP и WebSocket на `0.0.0.0:8080`; порт меняется через `PORT`. Для быстрой одиночной игры допустим `python3 -m http.server 8080`, но PvP при этом недоступен.
